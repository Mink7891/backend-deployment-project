### Конкуренция и транзакции PostgreSQL

| Проверка | Результат |
| --- | --- |
| 20 конкурентных холодных чтений | Один вызов провайдера, два снимка цен |
| 20 добавлений одной игры | Один успех, 19 конфликтов; один элемент и одно событие |
| 20 GET/PATCH и обновление | По-прежнему один вызов провайдера, два снимка и одно событие |
| Прямой rollback по шести таблицам | Исходные данные сохранены |
| Сбой Handler после INSERT | Транзакция откатилась, исходные данные сохранены |
| Одновременные refresh и DELETE | DELETE ждал освобождения родителя; оба Handler завершились без deadlock |

Детерминированный тест сначала выявил deadlock `SQLSTATE 40P01`.
Исправление задаёт порядок блокировок: игра → родительские wishlist
(`FOR KEY SHARE`) → элементы (`FOR UPDATE`). Повторный запуск подтвердил
защиту родителя, ожидание DELETE и отсутствие deadlock. SQLite-тесты
не заменяют эту проверку PostgreSQL.

Проверки воспроизводятся скриптами `scripts/verify_postgres.py`
и `scripts/verify_pg_delete_race.py`. Они используют mock и временные
собственные записи. После выполнения своих синтетических игр и списков
не осталось; прежний пользовательский wishlist сохранён.

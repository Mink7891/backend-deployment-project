# Чек-лист соответствия заданию

Источник: [требования проектной работы](https://buildin.ai/kseno/share/5256dbb3-06bd-4367-807e-e966a7794311?code=DFCSAS).
Для «отлично» нужны блоки А + Б + В и два дополнительных модуля. Тема проекта
не гарантирует оценку: требуется работающая система, отчёт и очная демонстрация.

Статус «подготовлено в коде» означает наличие реализации/конфигурации. Статус
«подтверждено» присваивается только после реального запуска и сохранения
доказательств. Этот файл не объявляет незапущенные проверки успешными.

## Что ещё надо подтвердить в реальной среде

1. Настроить две Linux-машины, Docker, Jenkins, реестр и Jenkins Credentials.
2. Выполнить pipeline: линтер → тесты → сборка → Trivy → push → deploy → smoke → нагрузка.
3. Сохранить JTL, HTML, JSON и графики на максимальной ступени. Обосновать p95.
4. Проверить CRITICAL gate и gate нагрузки на специально неуспешных результатах.
5. Показать реальное резервное копирование и восстановление в тестовую БД.
6. Развернуть следующую версию, затем прежний тег и проверить API после отката.
7. Подготовить Word-отчёт с фактическими данными и скриншотами, загрузить в СДО.

Не включайте значения API-ключей, пароли, приватные SSH-ключи и содержимое
credentials в скриншоты и отчёт. Записывайте commit SHA для каждого артефакта,
чтобы результаты было можно сопоставить с исходниками.
